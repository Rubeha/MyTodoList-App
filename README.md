# MyTodoList-App

A simple and responsive To-Do List application built with React and Vite to manage everyday tasks.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Validate empty task input
- Display an error message when the input is empty
- View the total number of tasks

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rubeha/MyTodoList-App.git
   ```

2. Navigate to the project folder:

   ```bash
   cd MyTodoList-App
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
